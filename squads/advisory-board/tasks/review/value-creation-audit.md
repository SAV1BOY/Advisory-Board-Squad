# Task: Value Creation Audit

## Objective
Assess whether the company is creating sustainable long-term value for all stakeholders. Go beyond financial metrics to evaluate moat strength, talent development, customer value, and societal impact as leading indicators of durable value creation.

## Trigger
- Annually as part of the board's strategic review
- Before a fundraise or exit event to articulate value creation narrative
- When financial metrics are strong but leading indicators suggest underlying weakness
- When preparing the annual board review report

## Agents Involved
- **Lead:** CEO with Strategy Lead and CFO
- **Support:** All functional leaders contributing their domain's value creation data
- **Advisory:** Full board participates in value creation discussion


## Agent Assignment
> Routing: see `config.yaml → routing → decision-quality-review`

- **Lead:** strategic-advisor (Peter Thiel)
- **Support:** capital-allocator (Charlie Munger), board-chair (Board Chair)
- **Review:** ethics-compass (Yvon Chouinard)

## Pre-Requisites
- [ ] Financial data current
- [ ] Moat tracker current
- [ ] Customer metrics current
- [ ] Employee metrics current
- [ ] Competitive data current

## Steps

1. **Step 1:** Assess financial value creation including revenue growth, margin improvement, capital efficiency, and return on invested capital

2. **Step 2:** Assess customer value creation including NPS, retention, expansion, time-to-value improvement, and customer outcomes

3. **Step 3:** Assess team value creation including talent density, skill development, promotion rate, and employer brand strength

4. **Step 4:** Assess competitive value creation including moat strength trajectory, market share, and competitive win rate

5. **Step 5:** Assess innovation value creation including R&D productivity, new product contribution, and platform value growth

6. **Step 6:** Synthesize findings into an overall value creation scorecard distinguishing between extractive growth and sustainable value creation

7. **Step 7:** Present to the board as part of the annual review with specific recommendations for improving value creation in underperforming dimensions

8. **Step 8:** Value Creation Audit Report; Multi-dimensional value scorecard; Comparison to prior year; Recommendations for value creation improvement

## Frameworks to Apply
- **Retrospective Analysis:** Structured look-back that separates process quality from outcome quality
- **Continuous Improvement Cycle:** Plan-Do-Check-Act applied to governance and management processes
- **Balanced Scorecard:** Multi-dimensional assessment that prevents over-indexing on any single metric

## Checklists

### Quality Gate
- [ ] Review is evidence-based with specific data points, not impressions
- [ ] Both positive and negative findings are presented honestly
- [ ] Root causes identified, not just symptoms
- [ ] Recommendations are specific, actionable, and resourced
- [ ] Historical comparison included to show trends
- [ ] Board has clear insight into what needs to change

## Output
- Strategic insights feed into annual-planning-session
- Moat findings feed into moat-review
- Financial efficiency findings feed into capital-allocation-review
- Customer value findings feed into product-strategy-review
- Talent value findings feed into people strategy
