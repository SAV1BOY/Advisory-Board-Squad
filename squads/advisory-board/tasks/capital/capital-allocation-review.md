# Task: Capital Allocation Review

## Objective
Review how the company's capital is being allocated across functions, initiatives, and time horizons. Ensure allocation aligns with strategic priorities and maximizes risk-adjusted returns. Identify misallocations and recommend rebalancing.

## Trigger
- Quarterly as part of the board review cycle
- When cash position falls below the board-approved minimum threshold
- Before any major new investment request
- After a significant strategic direction change

## Agents Involved
- **Lead:** CFO
- **Support:** CEO, functional leaders (for their budget areas)
- **Advisory:** Board finance committee or board members with financial expertise

## Pre-Requisites
- [ ] Current financial statements and cash position available
- [ ] Budget vs. actual reporting current for all departments
- [ ] Strategic priority list current (from annual planning or latest board session)
- [ ] Unit economics data current
- [ ] Any pending capital requests compiled

## Steps

1. **Current Allocation Mapping (Days 1-3)**
   - Map actual capital deployment across all functions and initiatives
   - Categorize spend: core operations, growth investments, maintenance, exploration, overhead
   - Compare actual allocation to the budget approved at the start of the period
   - Compare actual allocation to stated strategic priorities — are dollars going where strategy says they should?

2. **Return Analysis (Days 3-7)**
   - For each major investment: what was the expected return and what is the actual return to date?
   - Calculate ROI, payback period, and efficiency metrics for each investment category
   - Identify investments that are underperforming relative to projections
   - Identify investments that are outperforming and could benefit from increased allocation

3. **Runway and Cash Position Assessment (Days 5-7)**
   - Current cash position and burn rate
   - Runway under current spend trajectory
   - Runway under proposed reallocation scenarios
   - Sensitivity analysis: what happens if revenue misses plan by 10%, 20%, 30%?

4. **Rebalancing Options Development (Days 7-10)**
   - Develop 2-3 allocation scenarios: current trajectory, optimized for growth, optimized for runway
   - For each scenario: project cash position, growth rate, and risk profile over 12-18 months
   - Identify specific reallocation moves: what to increase, decrease, start, or stop
   - Quantify the impact of each reallocation on strategic priority progress

5. **Board Presentation (Days 10-15)**
   - Prepare the capital allocation memo using the capital-allocation-memo template
   - Present current allocation vs. strategy alignment
   - Present reallocation options with trade-offs
   - Request board direction on allocation priorities and any specific investment approvals

## Frameworks to Apply
- **Strategy-Allocation Alignment:** Map every dollar of spend to a strategic priority; flag unaligned spend
- **Portfolio Theory:** Balance the investment portfolio across risk/return profiles
- **Marginal Return Analysis:** Evaluate the next dollar in each category — where does the marginal dollar create the most value?
- **Zero-Based Assessment:** Challenge every line item as if building the budget from scratch

## Checklists

### Review Quality Gate
- [ ] All major spend categories mapped and categorized
- [ ] Actual allocation compared to both budget and strategic priorities
- [ ] Return metrics calculated for each major investment
- [ ] Runway analysis includes sensitivity scenarios
- [ ] Reallocation options include specific, actionable moves
- [ ] Cash reserves policy compliance verified

## Output
- Capital Allocation Review Report
- Current allocation map (visual)
- Return analysis by investment category
- Reallocation scenarios with trade-offs
- Updated runway model

## Handoffs
- Board allocation decisions update the operating budget
- Underperforming investments may trigger pivot-or-persevere reviews
- Runway concerns may trigger fundraising-plan development
- Investment approvals feed into execution-30-60-90 plans

## Metrics
| Metric | Target | Measurement |
|---|---|---|
| Strategy-allocation alignment | >80% of spend maps to top 3-5 strategic priorities | Allocation audit |
| Investment return accuracy | Forecast vs. actual within 25% for mature investments | Return analysis |
| Runway maintenance | Always >6 months at current burn | Cash model |
| Budget variance | Within 10% of approved budget per category | Financial reporting |
| Review completion time | Within 15 days of quarter close | Calendar |
