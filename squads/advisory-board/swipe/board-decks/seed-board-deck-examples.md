# Seed Board Deck Examples

## Overview
Seed-stage board decks should be concise (10-15 slides), focused on learning velocity and product-market fit progress, and honest about what's unknown. The board at this stage is more advisory than governance-focused.

## Recommended Structure

### Slide 1: Executive Summary
- One paragraph: what happened since last meeting, what matters most now, what you need from the board
- Keep it to 3 sentences max. The board should understand the state of the company in 30 seconds.

### Slide 2: Key Metrics Dashboard
| Metric | Last Month | This Month | Target | Trend |
|--------|-----------|------------|--------|-------|
| MRR | | | | |
| Active Users | | | | |
| Signup-to-Active Rate | | | | |
| Churn Rate | | | | |
| Cash Balance | | | | |
| Runway (months) | | | | |

### Slide 3: Product-Market Fit Progress
- Sean Ellis survey results (if available)
- Qualitative signals: customer quotes, usage patterns, organic growth indicators
- Product roadmap: what was shipped, what's next, what was deprioritized and why

### Slide 4: Customer / User Insights
- 3-5 key learnings from customer conversations
- What surprised you? What patterns are emerging?
- Customer persona refinement: is your target customer who you thought it was?

### Slide 5: Go-to-Market Experiments
- What acquisition channels were tested?
- Results: cost per lead, conversion rate, payback period
- What's working? What's not? What's next?

### Slide 6: Team
- Current team roster and key hires made
- Hiring plan for next quarter
- Any team concerns (retention, gaps, culture)

### Slide 7: Financials
- P&L summary (actual vs. plan)
- Cash position and burn rate
- Runway projection
- Key spending decisions upcoming

### Slide 8: Risks and Asks
- Top 3 risks the company faces right now
- Specific asks from the board: introductions, advice, decisions needed

## What NOT to Include at Seed Stage
- Detailed competitive analysis (you barely know your own market yet)
- 5-year financial projections (they're fiction at this stage)
- Elaborate org charts (you have 5-10 people)
- Glossy design (substance over style)

## Board Application
- At seed stage, the board's value is advice, introductions, and pattern-matching
- Focus discussion on learning velocity: is the team learning faster than competitors?
- Don't over-govern. The overhead of formal governance can kill speed at this stage.
