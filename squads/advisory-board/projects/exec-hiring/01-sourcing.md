# Exec Hiring: Sourcing

## Objective
Build a diverse, high-quality candidate pipeline through structured sourcing before evaluating any individual candidate.

## Inputs
- Approved role scorecard (00-role-scorecard.md).
- Network map: board, advisor, and leadership connections.
- Search firm options (if using external search).

## Process
1. Define target profile: ideal background, company stage experience, domain expertise.
2. Select sourcing channels: executive search firms, network referrals, direct outreach, inbound.
3. Set diversity targets for the candidate slate.
4. If using a search firm: negotiate terms, provide the scorecard, establish communication cadence.
5. Set pipeline targets: candidates sourced > screened > interviewed > finalist.
6. Begin outreach with a compelling role narrative tied to the company's mission and opportunity.
7. Track all candidates in the hiring registry.

## Tools/Frameworks
- `lib/components/hiring-blocks.md` (Block 2: Sourcing Strategy)
- `data/registries/hiring-registry.yaml` (pipeline tracking)

## Output
- Active candidate pipeline with 20+ sourced candidates.
- Shortlist of 8-12 candidates for screening interviews.
- Sourcing progress report to hiring committee.
