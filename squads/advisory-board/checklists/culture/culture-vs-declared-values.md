# Culture vs Declared Values Checklist

## Purpose
Measures the gap between the organization's declared values and its lived culture. Every organization has two cultures: the one on the wall and the one in the hallways. This checklist surfaces the discrepancies that create cynicism and undermine trust.

## When to Use
- Semi-annually during culture assessments.
- When employee engagement data suggests cultural disconnect.
- When values are being established or revised.
- When a cultural incident suggests values are not operational.

## Gate Criteria

### Gap Identification
- [ ] **Pass/Fail**: Each declared value has been tested against observable behavior in the last 90 days.
- [ ] **Pass/Fail**: Employees at multiple levels have been surveyed or interviewed about whether values are lived.
- [ ] **Pass/Fail**: Examples of values being upheld AND violated are documented.
- [ ] **Pass/Fail**: The gap between declared and lived values is assessed as narrow, moderate, or wide for each value.

### Enforcement
- [ ] **Pass/Fail**: At least one person has been held accountable for violating values in the last 12 months.
- [ ] **Pass/Fail**: Values violators at senior levels are held to the same standard as junior employees.
- [ ] **Pass/Fail**: Values are referenced in performance reviews, hiring decisions, and promotion criteria.
- [ ] **Pass/Fail**: There is a known, accessible way to report values violations without retaliation.

### Leadership Modeling
- [ ] **Pass/Fail**: Senior leaders can cite recent personal examples of living each value.
- [ ] **Pass/Fail**: Leaders model values visibly enough that others observe and reference their behavior.
- [ ] **Pass/Fail**: New leaders are explicitly assessed for values fit during hiring.

### Continuous Closing
- [ ] **Pass/Fail**: The biggest values-behavior gap has a named owner and an action plan to close it.
- [ ] **Pass/Fail**: Progress on closing gaps is tracked and reported.
- [ ] **Pass/Fail**: Values language evolves to remain relevant as the organization changes.

## Red Flags
- Employees laugh when values are mentioned.
- No one has ever been fired or reprimanded for violating values.
- Values were chosen by marketing, not by the team.
- "Culture fit" is used to discriminate rather than to assess values alignment.

## Escalation Triggers
- Employee surveys reveal a widening gap between declared and experienced culture.
- A public incident exposes a culture gap that damages reputation.
- A senior leader is credibly accused of systematically violating a core value.
- Regrettable attrition is linked to cultural hypocrisy.
