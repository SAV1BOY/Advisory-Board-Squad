# Annual Strategic Planning: OKRs and Milestones

## Objective
Translate strategic choices and resource allocation into measurable objectives, key results, and milestones that create accountability at every level of the organization.

## Inputs
- Strategic plan (02-strategic-choices.md). Resource allocation (03-resource-allocation.md). Current capabilities.

## Process
1. Define 3-5 company-level OKRs for the year. Each objective should be qualitative and inspiring; each key result should be quantitative and measurable.
2. Cascade OKRs to team and individual levels: each team's OKRs should visibly connect to a company OKR.
3. Define quarterly milestones for each company OKR.
4. For each key result, define: current baseline, target, data source, update cadence, and owner.
5. Define the dependency map: which OKRs depend on other OKRs?
6. Establish the OKR review cadence: weekly check-ins, monthly scoring, quarterly re-evaluation.
7. Communicate OKRs across the organization. Test alignment: can 10 random employees articulate the top 3 priorities?

## Tools/Frameworks
- `data/metrics/strategic-alignment-score.md` (alignment measurement)
- `scripts/tracking/scorecard-updater.md` (OKR tracking)
- `lib/components/strategy-blocks.md` Block 5 (Coherent Action Set)

## Output
Company, team, and individual OKRs. Quarterly milestone map. Dependency map. Review cadence established.
