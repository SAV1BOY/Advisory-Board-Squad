# Annual Strategic Planning: Resource Allocation

## Objective
Align resource allocation (people, capital, leadership attention) with strategic choices. Strategy is revealed by budgets, not slide decks.

## Inputs
- Strategic choices (02-strategic-choices.md). Current resource inventory. Financial model and budget.

## Process
1. Map current resource allocation against strategic priorities.
2. Identify misalignment: where are resources flowing to non-strategic activities?
3. Design the target allocation using capital-blocks.md Block 2.
4. Identify what must be stopped or reduced to free resources for strategic priorities.
5. For each strategic initiative, define: headcount needs, budget allocation, leadership time commitment.
6. Model the financial impact of the reallocation.
7. Build the hiring plan aligned with strategic priorities.
8. Get board approval on the resource allocation plan.

## Tools/Frameworks
- `lib/components/capital-blocks.md` Block 2 (Capital Allocation Framework)
- `lib/components/strategy-blocks.md` Block 4 (Resource Allocation)
- `lib/patterns/kill-decision-pattern.md` (for initiatives being defunded)

## Output
Resource allocation plan with budget, headcount, and leadership time distribution. Kill list for deprioritized activities. Board-approved budget.
