## Reading Priority Guide

**Priority 1 — Must Read Before Meeting (decision items):**
Documents requiring board decision. Without reading these, you cannot participate meaningfully in the discussion.

**Priority 2 — Should Read (discussion items):**
Documents informing board discussion. Reading these enables richer contribution.

**Priority 3 — For Reference (information items):**
Supporting data and standing reports. Skim unless a specific area concerns you.

## Quality Checklist (for Board Ops)

- [ ] All documents reviewed for completeness and formatting consistency
- [ ] Financial figures cross-checked between documents
- [ ] All documents are final versions (no drafts distributed)
- [ ] Confidential markings applied to sensitive documents
- [ ] Reading time estimates verified (assume 3 minutes per page average)
- [ ] Key questions drafted for each decision item
- [ ] Changes from prior package flagged
- [ ] Action item tracker current
- [ ] Package uploaded to board portal
- [ ] Distribution email sent with package summary
- [ ] Reminder sent to presenters about preparation and time limits
