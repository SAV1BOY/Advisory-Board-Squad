# Workshop Kit: Innovation Sprint

## Workshop Overview

**Duration:** Full day (6 hours with breaks) or split across two half-days
**Participants:** 8-12 people, cross-functional (product, engineering, design, sales, ops)
**Facilitator:** Internal or external; must enforce time constraints strictly
**Materials:** Whiteboard, sticky notes, dot stickers for voting, timer, printed customer data

## Purpose

Generate, evaluate, and prototype solutions to a specific strategic challenge in a single day. This is not a brainstorming session — it produces concrete concepts with defined next steps, assigned owners, and evaluation criteria.

## Pre-Sprint Preparation (1-2 Weeks Before)

### Define the Challenge
The sprint must focus on a single, well-defined challenge. Examples:
- "How might we reduce customer onboarding time from 14 days to 3 days?"
- "What product could we build for [adjacent market] using our existing capabilities?"
- "How do we respond to [competitor's] new offering?"

### Gather Input Data
- [ ] Customer interview summaries (5-10 recent interviews relevant to the challenge)
- [ ] Competitive analysis for the challenge area
- [ ] Internal performance data (metrics, usage analytics, support tickets)
- [ ] Technology capability assessment (what can we build with current stack and team?)
- [ ] Business constraints document (budget, timeline, regulatory, brand guidelines)

### Select Participants
- Include at least one person from each function that would be involved in execution
- Include one "outsider" — someone from a different team or discipline for fresh perspective
- Ensure a decision-maker is present who can authorize next steps
- Avoid more than 2 people from any single function

## Agenda

### Morning: Diverge (3 hours)

| Time | Activity | Duration |
|------|----------|----------|
| 9:00 | Opening: challenge statement, rules, and agenda | 15 min |
| 9:15 | Expert briefings: customer data, competitive landscape, constraints | 30 min |
| 9:45 | "How Might We" reframing exercise | 15 min |
| 10:00 | Individual ideation: Crazy 8s | 20 min |
| 10:20 | Break | 15 min |
| 10:35 | Solution sketching: detailed concepts (individual, silent) | 30 min |
| 11:05 | Gallery walk and heat map voting | 25 min |
| 11:30 | Concept clustering and selection (top 3-4 concepts) | 30 min |

### Afternoon: Converge (3 hours)

| Time | Activity | Duration |
|------|----------|----------|
| 12:00 | Lunch break | 45 min |
| 12:45 | Concept refinement: small groups flesh out top concepts | 45 min |
| 1:30 | Storyboarding: map the customer experience for each concept | 30 min |
| 2:00 | Break | 10 min |
| 2:10 | Feasibility assessment: effort, risk, and impact scoring | 30 min |
| 2:40 | Decision: select 1-2 concepts for prototyping | 20 min |
| 3:00 | Action planning: define next steps, owners, and timelines | 25 min |
| 3:25 | Closing: commitments and energy check | 5 min |

## Exercise Details

### How Might We (HMW) Reframing (15 min)
Take the challenge statement and reframe it as multiple "How Might We" questions:
- Original: "Onboarding takes too long"
- HMW: "How might we make onboarding feel instant even if setup takes time?"
- HMW: "How might we eliminate onboarding entirely?"
- HMW: "How might we make the onboarding process itself deliver value?"

Each participant writes 3-5 HMW questions on sticky notes. Group and vote on the most promising reframes.

### Crazy 8s (20 min)
- Fold a sheet of paper into 8 panels
- Set a timer for 8 minutes
- Sketch one distinct idea in each panel (1 minute per idea)
- Constraint forces quantity over quality — volume generates unexpected ideas
- No talking during this exercise

### Solution Sketching (30 min)
- Each participant selects their strongest idea from Crazy 8s
- Create a detailed, self-explanatory sketch or written concept on a single sheet
- Include: the core idea, how it works, who it serves, and why it wins
- Concepts must stand alone — they will be reviewed without verbal explanation

### Gallery Walk and Heat Map (25 min)
- Post all solution sketches on the wall
- Silent review: each participant walks the gallery and reads every concept
- Each participant gets 3 dot stickers to vote on concepts they find most promising
- Place dots on specific elements, not just on the overall concept

### Feasibility Assessment Matrix
Score each finalist concept (1-5 scale):

| Criteria | Definition | Concept A | Concept B | Concept C |
|----------|-----------|-----------|-----------|-----------|
| Customer Impact | How much does this improve the customer experience? | | | |
| Strategic Fit | How well does this align with company strategy? | | | |
| Technical Feasibility | Can we build this with current or near-term capabilities? | | | |
| Time to Value | How quickly can we deliver a testable version? | | | |
| Defensibility | Does this create a lasting advantage or is it easily copied? | | | |
| **Total** | | | | |

### Action Plan Template
For each selected concept:
- **Concept name:** [Clear, memorable name]
- **One-sentence description:** [What it is and who it serves]
- **Hypothesis:** [What we believe will happen if we build this]
- **Minimum viable test:** [Smallest thing we can build to test the hypothesis]
- **Owner:** [Single person accountable for next steps]
- **Timeline:** [Date for prototype/test completion]
- **Success criteria:** [How we will know if this works]
- **Kill criteria:** [What would tell us to stop pursuing this]

## Facilitation Rules

1. **Enforce time boxes ruthlessly.** The sprint works because of constraints, not despite them.
2. **Individual before group.** All ideation starts individually to prevent groupthink.
3. **No "yes, but" — only "yes, and."** During divergent phases, all ideas are valid.
4. **The decider decides.** If the group cannot reach consensus, the designated decision-maker chooses.
5. **Sketches over words.** Visual communication is faster and more precise than verbal description.
6. **No laptops during sessions.** Attention is the most valuable resource in the room.

## Post-Sprint Follow-Up

- **Within 48 hours:** Distribute sprint summary with selected concepts, owners, and timelines
- **Within 2 weeks:** Prototype review — owners present initial prototypes or test plans
- **Within 6 weeks:** Test results review — evaluate what was learned and decide to pursue, pivot, or kill
- **Quarterly:** Run innovation sprints on a regular cadence to build the muscle
