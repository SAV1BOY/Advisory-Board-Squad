# Strategic Reset: Metrics

## Objective
Define the measurement framework that will tell us whether the new strategy is working, providing early signal for course correction and preventing the organization from relying on hope rather than data.

## Inputs
- Execution plan with initiatives and milestones (03-execution-plan.md).
- Strategic assumptions that need to be validated.
- Historical baseline metrics for comparison.

## Process
1. Define 5-7 strategic KPIs: metrics that directly measure whether the strategy is achieving its objectives.
2. For each KPI: define the metric precisely, establish the current baseline, set targets (30/60/90/180/365 day), identify data sources, and assign a metric owner.
3. Define leading indicators: metrics that predict future strategic KPI performance (e.g., pipeline predicts revenue).
4. Define assumption validation metrics: for each critical assumption in the strategy, what data would confirm or falsify it?
5. Set review cadence: weekly operational metrics, monthly strategic metrics, quarterly strategic review.
6. Define pivot triggers: specific metric thresholds that should trigger a strategic reassessment.
7. Build the dashboard: create a single view that makes strategic health visible at a glance.

## Tools/Frameworks
- `data/metrics/` (all metric definitions for measurement standards)
- `scripts/tracking/scorecard-updater.md` (automated metric aggregation)
- `lib/components/strategy-blocks.md` (Block 6: Strategic Risk & Assumptions)
- `lib/utilities/scenario-table.md` (scenarios against which metrics are evaluated)

## Output
- Strategic metrics framework with KPIs, targets, data sources, and owners.
- Dashboard design (or specification for dashboard tool).
- Pivot trigger definitions with escalation procedures.
- Review cadence calendar scheduled for the next 12 months.
