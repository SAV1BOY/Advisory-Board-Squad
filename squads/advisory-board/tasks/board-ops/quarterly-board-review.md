# Task: Quarterly Board Review

## Objective
Conduct a comprehensive quarterly review of company performance, strategic progress, and risk posture with the board. This is the regular-cadence accountability and guidance mechanism.

## Trigger
- Every quarter, aligned with fiscal quarter close (typically 2-3 weeks after quarter end)

## Agents Involved
- **Lead:** CEO (content owner), Board Chair (facilitation)
- **Support:** CFO (financial review), Board Ops (logistics and materials)
- **Contributors:** Functional leaders for their sections of the review


## Agent Assignment
> Routing: see `config.yaml → routing → quarterly-board-review`

- **Lead:** board-chair (Board Chair)
- **Support:** governance-clerk (Simon Sinek), strategic-advisor (Peter Thiel), capital-allocator (Charlie Munger), talent-advisor (Patrick Lencioni), culture-steward (Brene Brown), risk-sentinel (Ray Dalio)

## Pre-Requisites
- [ ] Quarter has closed and financial data is available
- [ ] Board scorecard updated with current period data
- [ ] All functional leaders have submitted their inputs
- [ ] Prior quarter action items status collected

## Steps

1. **Data Collection (Close +5 days)**
   - CFO finalizes financial results for the quarter
   - Each functional leader submits their section of the quarterly report
   - Board Ops collects action item status updates
   - Risk register updated with current assessments

2. **Report Preparation (Close +7 days)**
   - CEO prepares the quarterly board review using quarterly-board-review.md template
   - CFO prepares the financial package with variance analysis
   - Board Ops prepares the board scorecard, action item tracker, and decision log updates
   - All materials reviewed for consistency and accuracy

3. **Package Assembly and Distribution (Close +10 days)**
   - Board Ops assembles the complete quarterly pre-read package
   - Chair reviews and approves the package
   - Package distributed to board members (minimum 5 business days before meeting)

4. **Board Meeting Execution (Close +15-20 days)**
   - Meeting run per the standard board meeting process (meeting-run.md)
   - Quarterly review is the primary agenda item
   - Focus discussion on: variances from plan, strategic priority progress, emerging risks
   - Capture decisions on any course corrections

5. **Post-Meeting Processing**
   - Minutes and follow-ups per minutes-and-followups.md
   - Quarterly review outcomes communicated to operating teams
   - Any strategic adjustments cascade to operating plans

## Frameworks to Apply
- **Red/Amber/Green Scoring:** RAG status across all dimensions of the scorecard
- **Variance Analysis:** Explain why actuals differ from plan; focus on material variances only
- **Trend Analysis:** More important than any single data point — where are we heading?

## Checklists

### Report Quality Gate
- [ ] All scorecard metrics updated with current quarter data
- [ ] Financial figures reconciled to official close
- [ ] Strategic priority progress assessed honestly (not everything is "on track")
- [ ] Top wins and misses are specific and quantified
- [ ] Risk register reflects current reality
- [ ] Forward guidance includes assumptions and confidence levels
- [ ] Help needed from board is specific and actionable

## Output
- Quarterly Board Review Report
- Updated board scorecard
- Updated risk register
- Meeting minutes with decisions and action items

## Handoffs
- Decisions feed into the decision log
- Action items tracked through action item tracker
- Insights inform next quarter's operating plan adjustments

## Metrics
| Metric | Target | Measurement |
|---|---|---|
| Report distribution timing | >5 business days before meeting | Calendar tracking |
| Data accuracy | Zero material corrections post-distribution | Error tracking |
| Board discussion quality | >60% of meeting time on strategic discussion (not information delivery) | Time tracking |
| Action item generation | 3-7 meaningful actions per meeting | Item counting |
| Board satisfaction with review quality | >4/5 | Periodic survey |
