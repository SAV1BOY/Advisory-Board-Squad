# Meeting Minutes

This directory stores meeting minutes for all advisory board and committee meetings.

Each file captures the agenda, attendees, discussion points, decisions made, and action items from a single meeting. Meeting minutes follow the structure defined in the **meeting-minutes-template**.

## Filing Convention

Files are named using the following format:

```
YYYY-MM-DD-meeting-type.md
```

- **YYYY-MM-DD** — Date the meeting took place.
- **meeting-type** — Lowercase, hyphen-separated description of the meeting type (e.g., `board-session`, `strategy-review`, `committee-sync`).

Example: `2026-03-15-board-session.md`
