# Task: Culture Code Update

## Objective
Review and refresh the company's culture code — its articulated values, operating principles, and behavioral norms — to ensure they remain relevant, authentic, and effective as the organization evolves. The culture code should reflect who the company is, guide decision-making, and support talent attraction and retention.

## Trigger
- Annual review as part of the strategic planning cycle
- Company has grown significantly (e.g., doubled headcount since last update)
- Culture health metrics indicate drift between stated and lived values
- Post-acquisition integration requiring cultural alignment
- Major strategic pivot that shifts how the company operates
- Founder or CEO transition

## Agents Involved
- **Lead:** CEO or CHRO
- **Support:** Leadership team, culture ambassadors, employee representatives
- **Advisory:** Board members, particularly those with organizational culture expertise

## Pre-Requisites
- [ ] Current culture code or values document
- [ ] Culture health survey data (recent engagement survey, pulse surveys)
- [ ] Employee feedback — interviews, focus groups, or anonymized comments
- [ ] Exit interview data themes
- [ ] Glassdoor and employer brand sentiment data
- [ ] Leadership team alignment on culture priorities

## Steps

1. **Culture Audit (Days 1-7)**
   - Review the current culture code — values, principles, and behavioral norms
   - Assess the gap between stated culture and lived culture using survey data and interviews
   - Identify values that are authentically lived and reinforced
   - Identify values that exist on paper but are not reflected in daily behavior
   - Gather input from employees at all levels — what do they experience as the real culture?
   - Review culture-related metrics — retention, engagement, inclusion, psychological safety

2. **Stakeholder Input Collection (Days 7-14)**
   - Conduct leadership team workshop on culture aspirations and concerns
   - Gather board input on culture expectations and governance alignment
   - Collect employee input through focus groups, surveys, or async channels
   - Interview recent hires (what culture did they expect vs. experience?)
   - Interview departing employees or review exit interview themes
   - Benchmark against admired company cultures in the industry

3. **Values and Principles Refresh (Days 14-21)**
   - Draft updated values — remove values that are not authentic, add values that have emerged organically
   - For each value, define specific behavioral expectations — what does this look like in practice?
   - Define anti-patterns for each value — what behaviors violate this value?
   - Ensure values are memorable, actionable, and differentiating (not generic)
   - Pressure-test values against real decisions — would these values guide the right choice in a hard situation?
   - Limit to 4-6 core values for memorability and focus

4. **Integration and Operationalization Plan (Days 21-28)**
   - Define how values will be embedded in hiring — interview questions, evaluation criteria
   - Define how values will be embedded in performance reviews — behavioral assessment rubric
   - Define how values will be embedded in promotion and leadership decisions
   - Plan the communication rollout — all-hands, internal messaging, visual artifacts
   - Identify culture rituals and practices to reinforce the updated code
   - Define culture metrics and measurement cadence

5. **Board Review and Organizational Rollout (Days 28-35)**
   - Present the updated culture code to the board for endorsement
   - Launch the updated culture code to the full organization
   - Equip managers with discussion guides for team-level conversations
   - Update external-facing materials (careers page, recruiting materials)
   - Schedule the first culture health check under the new code (90 days post-launch)

## Frameworks to Apply
- **Values Authenticity Test:** Each value must be observable in current behavior, not just aspirational
- **Trade-Off Test:** A meaningful value implies a trade-off — if the opposite is absurd, the value is too generic
- **Behavioral Anchoring:** Each value has specific, observable behaviors attached
- **Culture as Operating System:** Values guide decisions when no specific policy exists

## Checklists

### Quality Gate
- [ ] Culture audit conducted with data from multiple sources (surveys, interviews, metrics)
- [ ] Employee voice included in the process at all levels, not just leadership
- [ ] Updated values are specific, memorable, and actionable (not generic platitudes)
- [ ] Each value has defined behaviors and anti-patterns
- [ ] Operationalization plan connects values to hiring, performance, and promotion
- [ ] Board has endorsed the updated culture code
- [ ] Communication plan reaches all employees with manager-led discussion

## Output
- Updated culture code document
- Behavioral rubric for each value (for use in hiring and performance reviews)
- Culture communication and rollout plan
- Culture measurement framework and baseline metrics
- Board endorsement recorded in decision log

## Handoffs
- Updated values feed into exec-hiring interview criteria
- Behavioral rubric feeds into performance-review-exec task
- Culture metrics feed into culture-audit and culture-health-report
- Employer brand materials feed into recruiting and talent-pipeline efforts
- Culture health monitoring feeds into team-health-check task

## Metrics
| Metric | Target | Measurement |
|---|---|---|
| Employee values awareness | >90% can name core values | Quarterly pulse survey |
| Values-behavior alignment | >75% rate values as "lived daily" | Culture health survey |
| Engagement score post-update | Improvement from baseline | Engagement survey comparison |
| Hiring values-fit assessment | 100% of interviews include values assessment | Hiring process audit |
| Culture code refresh cadence | Reviewed annually, updated as needed | Calendar |
