# Exec Hiring: References

## Objective
Conduct thorough reference checks — both provided and backchannel — to validate interview findings and surface information that candidates cannot or will not reveal.

## Inputs
- Finalist candidates (02-interviews.md).
- Interview scorecards with areas to validate.
- Reference check questions mapped to scorecard competencies.

## Process
1. Collect 3-4 provided references per finalist: former managers, peers, and direct reports.
2. Conduct 2+ backchannel references per finalist through board and network connections.
3. Ask standardized questions mapped to scorecard competencies.
4. Specifically probe: leadership under pressure, team retention, integrity, and adaptability.
5. Listen for what is NOT said — reference checks are as much about tone and hesitation as content.
6. Synthesize findings into a reference summary for each finalist.
7. Flag any red flags for immediate discussion with the hiring committee.

## Tools/Frameworks
- `lib/components/hiring-blocks.md` (Block 4: Reference Architecture)
- `archive/hiring-misses/exec-mismatch-lessons.md` (patterns to watch for)

## Output
- Reference summary for each finalist.
- Red flag report (if any).
- Updated candidate assessment incorporating reference findings.
