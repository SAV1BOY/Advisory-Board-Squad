# Language Guide: Memo Writing Style

## Purpose

This guide defines how Advisory Board memos are written — pre-reads, decision memos, strategy briefs, and any document that goes to the board in written form. The standard is: a busy, intelligent reader should extract the key message in 60 seconds and the full argument in 5 minutes.

## Structure

Every board memo follows this skeleton:

### 1. Header Block

```
Title: [Descriptive title — not clever, not vague]
Author: [Name]
Date: [YYYY-MM-DD]
Type: [Decision / Information / Discussion]
Read time: [X minutes]
```

### 2. The Bottom Line (first paragraph)

State the conclusion, recommendation, or key finding in the first paragraph. Do not build up to it. The reader should know the point before reading the argument.

For decision memos: "I recommend we [action] because [core reason]. The expected outcome is [specific result]. The main risk is [specific risk]."

For information memos: "The key finding is [finding]. The implication for the board is [implication]."

### 3. Context (second section)

Provide the minimum context a reader needs to evaluate the bottom line. Not the full history — only what is relevant to this decision or finding.

- What is the situation?
- What changed? (If nothing changed, why are we discussing this now?)
- What constraints apply?

### 4. Analysis (core of the memo)

Present the evidence and reasoning that supports the bottom line.

- For decision memos: present the options considered, the evaluation criteria, and how each option scored.
- For information memos: present the data, the methodology, and the interpretation.
- For discussion memos: present the tension, the different perspectives, and the open questions.

### 5. Risks & Mitigations

What could go wrong? For each risk, what is the mitigation?

### 6. Ask

What does the author need from the board? Be specific:
- "Approve option B."
- "Provide feedback on the approach."
- "Decide between options A and C."
- "Note this information; no action required."

## Writing Rules

### Sentences

- Average sentence length: 15-20 words. No sentence over 35 words.
- Active voice. "The team completed the analysis" not "The analysis was completed."
- One idea per sentence. If a sentence has two clauses joined by "and," consider splitting.
- Lead with the subject. "Revenue grew 14 %" not "In terms of top-line performance, revenue experienced growth of 14 %."

### Paragraphs

- One point per paragraph. If you are making a new point, start a new paragraph.
- Maximum 5 sentences per paragraph. If it is longer, it contains multiple points.
- Topic sentence first. The first sentence of every paragraph states the paragraph's point.

### Data

- Use numbers, not adjectives. "Revenue grew 14 %" not "Revenue grew significantly."
- Include the comparison. "Revenue grew 14 % vs. 10 % plan" not just "Revenue grew 14 %."
- Round appropriately. "$4.2M" not "$4,237,891.23" unless the precision matters.
- Source your data. "(Source: Q3 finance report, Sep 2025)" in parentheses or footnotes.

### Length

- **Pre-read memos:** 2 pages maximum. If you cannot make the case in 2 pages, you do not understand it well enough.
- **Decision memos:** 1-3 pages depending on complexity. The decision itself should be statable in one sentence.
- **Information memos:** 1-2 pages. Detail goes in appendices.
- **Appendices** are for supporting data, detailed analysis, and reference material. They are optional reading, not required.

### Formatting

- Use headers to create scannable structure.
- Use tables for comparisons. Three options with five criteria is a table, not five paragraphs.
- Use bullet lists for sets of items. Narrative for arguments and reasoning.
- Bold the most important sentence in each section — one sentence only.
- No decorative formatting. No colored text, no clip art, no unnecessary graphics.

## Common Mistakes

| Mistake | Fix |
|---|---|
| Burying the lead | Move the conclusion to the first paragraph |
| Context overload | Include only context the reader needs to evaluate the recommendation |
| Passive voice to avoid accountability | Use active voice and name the responsible person |
| Adjectives instead of data | Replace every adjective with a number |
| Options without criteria | State the evaluation criteria before presenting options |
| Missing the ask | End every memo with a specific, actionable ask |
| Too long | If it exceeds the page limit, cut. Then cut again. |

## Review Checklist

Before submitting a board memo, verify:

- [ ] Bottom line is in the first paragraph.
- [ ] A reader can get the point in 60 seconds by reading only headers and first sentences.
- [ ] Every claim is supported by data or explicit reasoning.
- [ ] Active voice throughout.
- [ ] No sentence over 35 words.
- [ ] No paragraph over 5 sentences.
- [ ] The ask is specific and actionable.
- [ ] Length is within the limits.
- [ ] Formatting aids scanning (headers, tables, bold for key points).
- [ ] Someone unfamiliar with the topic can follow the argument.
