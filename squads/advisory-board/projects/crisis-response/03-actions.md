# Crisis Response: Resolution Actions

## Objective
Address the root cause of the crisis and implement permanent fixes to prevent recurrence.

## Inputs
- Containment success (01-containment.md). Root cause analysis findings.

## Process
1. Conduct root cause analysis: 5 Whys, fault tree analysis, or timeline reconstruction.
2. Identify contributing factors: process, information, capability, judgment, incentives, communication.
3. Define resolution actions for root cause and each significant contributing factor.
4. Assign single owners and deadlines for each action.
5. Define verification: how will we confirm the fix works?
6. Define recurrence prevention: structural changes to prevent similar crises.
7. Track resolution actions in the action item tracker.

## Tools/Frameworks
- `lib/components/crisis-blocks.md` (Block 5: Root Cause and Resolution)
- `lib/patterns/postmortem-pattern.md` (root cause methodology)
- `scripts/tracking/action-item-tracker.md`

## Output
Root cause analysis document. Resolution action plan with owners and deadlines. Recurrence prevention measures.
