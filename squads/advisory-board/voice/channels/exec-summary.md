# Channel Guide: Executive Summary

## When to Use

The executive summary is a standalone document that distills a complex topic into a single page for senior decision-makers. Use it for:

- Condensing a longer report or analysis for board consumption.
- Briefing the CEO or exec team on a board discussion outcome.
- Providing a partner, investor, or external stakeholder with a quick overview.
- Summarizing cross-squad strategic handoffs.

## Format

### Length
One page. Absolute maximum: two pages. If it requires more, the author does not understand the material well enough.

### Structure

```
EXECUTIVE SUMMARY
[Title]
[Date] | [Author] | [Confidentiality level]

BOTTOM LINE
[2-3 sentences: the single most important takeaway.
If the reader reads nothing else, they get the point here.]

SITUATION
[3-5 sentences: what is happening and why it matters.
Context only — no analysis yet.]

KEY FINDINGS / ANALYSIS
[3-5 bullet points. Each bullet is one complete thought.
Lead each bullet with the finding, follow with the evidence.]

• [Finding]: [Supporting evidence or data]
• [Finding]: [Supporting evidence or data]
• [Finding]: [Supporting evidence or data]

RECOMMENDATION
[1-3 sentences: what should be done.
Specific, actionable, with owner if applicable.]

RISKS / CONSIDERATIONS
[2-3 bullets: what could go wrong, what tradeoffs exist.]

NEXT STEPS
[2-3 bullets: specific actions, owners, and dates.]
```

## Writing Rules

### The Bottom Line
- Written last, placed first.
- Must make sense to someone who has zero context.
- Should answer: "So what? What does this mean for us?"

### Situation
- Only include what the reader needs to evaluate the findings and recommendation.
- One paragraph maximum. If you need more context, link to the full report.
- Do not repeat information from the bottom line.

### Key Findings
- Each bullet starts with the insight, not the methodology.
- "Customer retention dropped 8 points to 86 %" not "Our analysis of customer data revealed..."
- Include the number or evidence that makes each finding credible.
- Prioritize: most important finding first.

### Recommendation
- Use imperative language: "Approve...", "Invest...", "Discontinue...", "Defer until..."
- If there are multiple options, state which one you recommend and why.
- Name the owner if the recommendation involves an action.

### Risks
- Only material risks. If a risk wouldn't change the recommendation, it doesn't belong here.
- Include the mitigation if one exists.

### Next Steps
- Each step has an owner and a deadline.
- Maximum 3 steps. If there are more, the first step is "develop a detailed plan."

## Tone

- **Declarative.** State conclusions, don't hedge.
- **Data-driven.** Every claim has a number or specific evidence.
- **Neutral.** Let the evidence speak. Save advocacy for the recommendation section.
- **Scannable.** A reader should absorb the key points in 90 seconds.

## Example

```
EXECUTIVE SUMMARY
Q3 Customer Health Assessment
2026-03-01 | Strategy-Analyst | Board Confidential

BOTTOM LINE
Customer retention declined for the second consecutive quarter,
driven by enterprise segment churn. If the trend continues,
ARR will miss the annual target by $1.8M. The root cause is
onboarding quality, not product fit.

SITUATION
Enterprise retention dropped from 94% to 86% between Q1-Q3.
Three enterprise customers churned in Q3 citing poor onboarding
experience and slow time-to-value. Mid-market and SMB retention
remains stable at 91% and 88% respectively.

KEY FINDINGS
• Enterprise onboarding takes 47 days vs. 21-day target.
  The bottleneck is implementation engineering capacity.
• Churned customers shared a pattern: no dedicated success
  manager assigned in the first 14 days.
• Product NPS remains strong (62) across all segments,
  confirming the issue is onboarding, not product.
• Competitor X launched a white-glove onboarding program
  in Q2 and is winning in competitive deals.

RECOMMENDATION
Hire 2 implementation engineers and 1 enterprise success manager
within 60 days. Estimated cost: $420K annually. Expected impact:
reduce onboarding time to 25 days and recover enterprise
retention to 92%+ by Q1 next year.

RISKS
• Hiring timeline may exceed 60 days in the current market.
  Mitigation: engage a contractor agency as backup.
• Root cause may be partially product-related despite strong
  NPS. Mitigation: exit interviews for next 3 churns to validate.

NEXT STEPS
• [VP Customer Success]: Submit hiring plan by March 15.
• [Strategy-Analyst]: Present full analysis at March 25 board
  meeting.
• [CEO]: Approve interim contractor budget ($80K) by March 10.
```

## Anti-Patterns

| Anti-Pattern | Problem | Fix |
|---|---|---|
| Summary is as long as the report | Defeats the purpose | One page hard limit. Cut ruthlessly. |
| No bottom line | Reader has to read the whole thing to get the point | Write the bottom line first. If you can't, you're not clear on the point. |
| Methodology in findings | "We conducted a survey of 200 customers..." | Lead with the insight. Methodology goes in the full report. |
| Recommendation without evidence | "We should invest in X" with no supporting data | Every recommendation traces back to a specific finding |
| Passive voice | "It was determined that..." | Active: "The analysis shows..." or "We found..." |
| No next steps | Reader agrees but doesn't know what to do | Always end with specific, owned, dated next steps |
