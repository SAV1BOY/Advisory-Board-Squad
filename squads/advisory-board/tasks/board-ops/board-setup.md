# Task: Board Setup

## Objective
Establish the advisory board from scratch — define composition, governance structure, operating cadence, and supporting infrastructure. This task covers the full lifecycle from deciding to form a board through the first meeting.

## Trigger
- Company reaches a stage where board-level governance is needed (post-seed, Series A, or founder decision)
- Existing informal advisors need to be formalized into a structured board
- Investor term sheet requires board formation
- CEO or founders decide strategic advisory input is needed

## Agents Involved
- **Lead:** CEO / Founder
- **Support:** Legal counsel, existing investors, Board Ops (once hired/assigned)
- **Advisory:** Existing advisors or mentors with board experience

## Pre-Requisites
- [ ] Company has a clear strategic direction (even if evolving)
- [ ] Founder/CEO has identified the types of expertise needed on the board
- [ ] Legal entity is properly formed with corporate documents in order
- [ ] Budget allocated for board operations (meeting costs, tools, potential compensation)
- [ ] At least one candidate board member identified

## Steps

1. **Define Board Purpose and Mandate (Week 1)**
   - Articulate why the board exists: governance, strategy, accountability, or all three
   - Write a 1-page Board Charter defining scope, authority, and relationship to management
   - Determine whether this is a formal board of directors or an advisory board (different legal implications)
   - Decide on board size (3-7 members is typical for early-stage)

2. **Map Required Competencies (Week 1-2)**
   - Complete a skills matrix identifying gaps in the founding team's expertise
   - Prioritize: which 3-5 competencies would create the most value on the board?
   - Consider diversity across: industry experience, functional expertise, stage experience, network, demographics
   - Document the ideal board composition profile

3. **Recruit Board Members (Weeks 2-8)**
   - Build a target list of 15-20 potential board members
   - Leverage investor networks, advisor relationships, and industry connections
   - Conduct introductory conversations focused on mutual fit
   - Evaluate candidates against the competency matrix
   - Check references (ask their previous founders/CEOs about their board behavior)
   - Extend invitations with clear expectations document

4. **Establish Governance Documents (Weeks 4-6)**
   - Draft and approve Board Charter
   - Draft board member agreement (expectations, confidentiality, compensation, term)
   - Establish conflict of interest policy
   - Define decision-making framework (what requires board approval vs. management authority)
   - Set information rights and confidentiality standards

5. **Set Up Operating Infrastructure (Weeks 5-7)**
   - Select board portal or document management system
   - Create template library (use templates in this squad's templates/ directory)
   - Set up secure communication channel for board members
   - Establish the board calendar for the next 12 months
   - Assign Board Ops responsibilities (who prepares materials, takes minutes, tracks actions)

6. **Design Meeting Cadence (Week 6)**
   - Set regular meeting frequency (monthly for early-stage advisory, quarterly for formal boards)
   - Block dates for the full year
   - Define meeting duration and format (in-person, virtual, hybrid)
   - Create standard agenda template
   - Establish pre-read distribution timeline (5+ business days before meetings)

7. **Prepare for First Meeting (Weeks 7-8)**
   - Prepare comprehensive company overview package
   - Create the first board scorecard with baseline metrics
   - Draft the first meeting agenda
   - Send welcome package to all board members
   - Conduct 1:1 pre-calls with each board member to build rapport and set expectations

8. **Run First Meeting and Calibrate (Week 8-9)**
   - Execute first meeting using the board-agenda template
   - Capture minutes and action items
   - Collect feedback from each board member within 48 hours
   - Adjust cadence, format, and content based on feedback
   - Document lessons learned for the operating playbook

## Frameworks to Apply
- **Skills Matrix:** Map board member competencies against company needs
- **RACI:** Define roles for board vs. management across key decisions
- **Governance Maturity Model:** Assess current governance maturity and target state

## Checklists

### Board Composition Quality Gate
- [ ] At least one member with deep industry expertise
- [ ] At least one member with financial/capital markets expertise
- [ ] At least one member with operational scaling experience at relevant stage
- [ ] Board includes diverse perspectives (background, experience, thinking style)
- [ ] No member has an unmanageable conflict of interest
- [ ] All members have committed to the expected time investment

### Infrastructure Quality Gate
- [ ] Board portal or document system is operational
- [ ] All governance documents are signed
- [ ] Communication channels are established and tested
- [ ] Calendar is set for next 12 months
- [ ] Template library is populated and accessible
- [ ] Board Ops role is assigned with clear responsibilities

## Output
- Signed Board Charter
- Signed board member agreements for all members
- Skills matrix (populated)
- Board calendar (12 months)
- First meeting minutes and action items
- Board operating playbook (how we run our board)

## Handoffs
- Board Ops takes over ongoing meeting preparation (see: meeting-prep.md)
- CEO establishes 1:1 cadence with each board member
- Board scorecard enters regular update cycle (see: update-board-scorecard.md)
- Decision log is initialized (see: update-registries.md)

## Metrics
| Metric | Target | Measurement |
|---|---|---|
| Time from decision to first meeting | <8 weeks | Calendar tracking |
| Board member acceptance rate | >60% of invitations | Tracking |
| First meeting NPS (board member satisfaction) | >8/10 | Post-meeting survey |
| Skills matrix coverage | >80% of identified needs | Matrix audit |
| Governance documents completion | 100% | Checklist |
