# Framework Selection Guide

## Purpose

The Advisory Board uses multiple decision and analytical frameworks. This guide helps agents select the right framework for the right situation. Using the wrong framework wastes time; using no framework produces inconsistent results.

## Framework Index

### Strategic Analysis Frameworks

| Framework | Use When | Key Output |
|---|---|---|
| **SWOT Analysis** | Annual planning, environmental scan | Strengths, weaknesses, opportunities, threats |
| **Porter's Five Forces** | Industry attractiveness assessment | Competitive intensity, supplier/buyer power, substitution/entry threats |
| **Moat Analysis** | Evaluating competitive advantage durability | Network effects, switching costs, scale, brand, IP, cost advantage |
| **Blue Ocean / Red Ocean** | Deciding whether to compete or create new market space | Value innovation, uncontested market space |
| **Jobs-to-be-Done** | Product strategy, customer understanding | Functional, social, and emotional jobs customers are hiring the product for |

### Decision Frameworks

| Framework | Use When | Key Output |
|---|---|---|
| **Expected Value (EV)** | Quantifiable outcomes with estimable probabilities | Probability-weighted value of each option |
| **Decision Matrix** | Multiple options against multiple criteria | Weighted score for each option |
| **Pre-Mortem** | Before committing to a major decision | List of failure modes and prevention measures |
| **Inversion** | Complex problem where direct analysis is difficult | Failure conditions that must be avoided |
| **Regret Minimization** | Irreversible decisions with long time horizons | Choice you'd least regret in 10 years |
| **One-Way/Two-Way Door** | Calibrating decision speed | Reversible (decide fast) vs. irreversible (decide carefully) |

### Financial Frameworks

| Framework | Use When | Key Output |
|---|---|---|
| **DCF / NPV** | Long-term investment evaluation | Present value of future cash flows |
| **Scenario Analysis** | Uncertain outcomes with distinct possible paths | Three scenarios (base/upside/downside) with probabilities |
| **Sensitivity Analysis** | Understanding which inputs matter most | Key drivers and their impact on outcome |
| **Unit Economics** | Evaluating business model viability | CAC, LTV, payback period, contribution margin |
| **Portfolio Analysis** | Comparing multiple investments simultaneously | Risk-return profile of the full portfolio |

### Organizational Frameworks

| Framework | Use When | Key Output |
|---|---|---|
| **Scorecard (Hiring)** | Executive hiring decisions | Competency and outcome ratings for candidates |
| **RACI** | Clarifying roles on cross-functional initiatives | Responsible, Accountable, Consulted, Informed for each activity |
| **Org Health Diagnostic** | Assessing organizational effectiveness | Root causes of dysfunction with severity ratings |
| **Culture Audit** | Evaluating values alignment and cultural health | Gap between stated values and lived behaviors |

### Risk Frameworks

| Framework | Use When | Key Output |
|---|---|---|
| **Risk Matrix** | Assessing and prioritizing risks | Likelihood x Impact scores |
| **Stress Test** | Testing resilience against extreme scenarios | Exposure and preparedness for tail events |
| **Black Swan Exercise** | Identifying catastrophic low-probability risks | List of tail risks with contingency plans |

## Selection Decision Tree

```
What type of question are you answering?

├── "Should we do X?" (Yes/No decision)
│   ├── Reversible? → One-Way/Two-Way Door → If two-way, decide fast
│   └── Irreversible? → Pre-Mortem + Expected Value
│
├── "Which option should we choose?" (Multiple options)
│   ├── Quantifiable outcomes? → Expected Value + Scenario Analysis
│   └── Qualitative factors? → Decision Matrix with weighted criteria
│
├── "What is our strategic position?" (Assessment)
│   ├── Industry level? → Five Forces
│   ├── Company level? → SWOT + Moat Analysis
│   └── Product level? → Jobs-to-be-Done
│
├── "Is this investment worth it?" (Financial)
│   ├── Single investment? → DCF/NPV + Sensitivity Analysis
│   └── Multiple investments? → Portfolio Analysis + Scenario Analysis
│
├── "What could go wrong?" (Risk)
│   ├── Known risks? → Risk Matrix
│   ├── Extreme scenarios? → Stress Test
│   └── Unknown unknowns? → Black Swan Exercise + Inversion
│
└── "What's wrong with our organization?" (Org health)
    ├── Culture? → Culture Audit
    ├── Effectiveness? → Org Health Diagnostic
    └── Role clarity? → RACI
```

## Combining Frameworks

Most complex decisions benefit from multiple frameworks:

- **Capital allocation:** Expected Value + Scenario Analysis + Pre-Mortem + Portfolio Analysis.
- **Strategy refresh:** SWOT + Five Forces + Moat Analysis + Inversion.
- **M&A evaluation:** DCF/NPV + Scenario Analysis + Risk Matrix + Scorecard (for team assessment).
- **Executive hiring:** Scorecard + Culture Audit (fit assessment) + Pre-Mortem.
- **Crisis response:** Risk Matrix + Stress Test + Scenario Analysis (rapid versions).

## Anti-Patterns

| Anti-Pattern | Problem | Fix |
|---|---|---|
| Framework worship | Forcing every situation into a specific framework | Select the framework for the situation, not the other way around |
| No framework | Making decisions based on gut feel and persuasion | Always use at least one structured framework for Type 1 and Type 2 decisions |
| Framework overload | Using 5 frameworks when 2 would suffice | Apply the selection tree; rarely need more than 2-3 frameworks for any decision |
| Mismatched framework | Using SWOT for a financial investment decision | Match the framework to the question type |
