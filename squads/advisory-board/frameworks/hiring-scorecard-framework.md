# Hiring Scorecard Framework

## Purpose

The Hiring Scorecard Framework provides a structured, evidence-based method for evaluating candidates that replaces gut-feel hiring with rigorous assessment. Each candidate is scored against predefined criteria before any interviews begin, ensuring consistency, reducing bias, and creating a defensible record of hiring decisions. The scorecard approach, championed by Geoff Smart and Randy Street in "Who," dramatically improves hiring accuracy.

## When to Use

- For every hire, but especially for senior and critical roles
- When current hiring produces inconsistent results
- When hiring decisions are being made on "vibes" rather than evidence
- When building a hiring process for a scaling organization
- When integrating cultural values into the hiring process

## Core Model

### Scorecard Components

**1. Mission:** What does this role exist to accomplish? One sentence.
**2. Outcomes:** 3-5 specific, measurable results this person must deliver in their first 12 months.
**3. Competencies:** 5-8 behavioral and technical competencies required. Each defined with observable behaviors.
**4. Cultural Fit:** 2-3 cultural criteria aligned with organizational values (e.g., Lencioni's Humble/Hungry/Smart).

### Scoring
Each criterion is scored 1-5 by each interviewer independently:
- 5: Exceptional evidence of this competency
- 4: Strong evidence
- 3: Adequate evidence
- 2: Weak evidence
- 1: No evidence or negative evidence

### The Debrief
After all interviews, the hiring team compares scores. Discrepancies (where one interviewer scores 5 and another scores 2) are the most valuable data points — they reveal either a bias or information one interviewer has that others don't.

## Steps

1. **Write the scorecard before posting the role.** Define mission, outcomes, competencies, and cultural criteria.
2. **Design interviews around the scorecard.** Each interview should assess specific scorecard criteria.
3. **Train interviewers on scoring.** Calibrate what a 3 vs. 5 looks like for each criterion.
4. **Score independently.** Each interviewer scores before the debrief discussion.
5. **Debrief by examining discrepancies.** Don't average — investigate why scores differ.
6. **Make the decision based on the scorecard.** The candidate who scores highest on the most important criteria gets the offer.
7. **Archive the scorecard.** Compare the hiring prediction to actual performance at 6 and 12 months.

## Application Guidelines

### For Board Advisors
- Help founders build structured hiring processes early. Ad-hoc hiring produces ad-hoc teams.
- For executive hires, participate in scorecard design — the board should agree on what the role needs to accomplish.
- Use scorecards to reduce hiring bias. Structured evaluation dramatically outperforms unstructured interviews.

## Common Mistakes

1. **No scorecard.** Interviewing without predefined criteria produces unreliable assessments.
2. **Post-hoc criteria.** Defining what you're looking for after meeting candidates biases toward whoever you liked.
3. **Averaging scores.** A candidate with all 3s is very different from one with 5s and 1s. Investigate the variance.
4. **Cultural fit as homogeneity.** Cultural fit means values alignment, not personality similarity.

## Output Format

```markdown
# Hiring Scorecard: [Role]

## Mission: [One sentence]

## Required Outcomes (12 months)
1. [Outcome]
2. [Outcome]
3. [Outcome]

## Competency Scores

| Competency | Interviewer A | Interviewer B | Interviewer C | Avg | Discrepancy? |
|-----------|:------------:|:------------:|:------------:|:---:|:------------:|
| | | | | | |

## Cultural Fit
| Criterion | Score (1-5) | Evidence |
|-----------|:----------:|---------|
| | | |

## Decision: Hire / No-Hire
## Confidence: [%]
```

## Related Frameworks

- **Lencioni Ideal Team Player** — Humble/Hungry/Smart as cultural criteria
- **Lencioni Working Genius** — Genius type as role-matching criteria
- **Principal-Agent Framework** — Hiring is adverse selection mitigation
- **Hoffman Alliance Framework** — Define the tour of duty in the scorecard
