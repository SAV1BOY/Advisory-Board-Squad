# Decisions

This directory stores finalized decision records produced by the advisory board and leadership team.

Each file represents a single decision that has been formally approved and documented. Decision records follow the structure defined in the **decision-memo-template** and are tracked in the **decision-registry** (`data/registries/decision-registry.yaml`).

## Filing Convention

Files are named using the following format:

```
YYYY-MM-DD-decision-title.md
```

- **YYYY-MM-DD** — Date the decision was made.
- **decision-title** — Lowercase, hyphen-separated summary of the decision.

Example: `2026-03-15-expand-into-latam-market.md`
